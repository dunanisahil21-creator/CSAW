# AI Interaction Logs

Per the challenge rules, this directory documents **every** use of generative AI in producing
this submission. All hardware (clean RTL, Trojan, testbenches) and the key-recovery tooling were
generated by AI; no hardware was written by a human.

- **Model:** Claude (Anthropic).
- **Interaction mode:** agentic **Claude Code** environment — the model was given direct tool
  access to a shell, Icarus Verilog (`iverilog`/`vvp`), and a C compiler, and ran an autonomous
  **generate → simulate → inspect → repair** loop rather than copy-pasting from a chat UI.
- **Supporting framework around the model:**
  - A C **known-plaintext key-search** the model wrote, compiled, and ran to recover `K`.
  - A **code generator** the model wrote to emit the S-box tables directly into the Verilog
    (removing hand-transcription error).
  - **Simulation-in-the-loop**: every artifact was compiled and run, and the model iterated on
    the actual simulator output until all checks passed.

See [`development_log.md`](development_log.md) for the full chronological record of prompts,
AI reasoning/actions, and outputs.
